DNS Takeover Architecture

为什么传统 OpenWrt 插件改 DNS 总失效？

许多软路由安装了 HomeProxy 或 sing-box，它们在 Nat 规则中拥有极高的优先度，会直接在 LAN 53 端口前拦截所有流量送进代理 TUN，被压在后面的 dnsmasq 上游修改完全无效！AtomDNS 采用更早的 priority 规则，彻底破解劫持冲突。

Netfilter (nftables) 链路优先级竞争分析

优先级数值越小越先被执行（数值低优先命中）

AtomDNS 绝对优先胜出
执行链 / 来源 Priority (优先级) 捕获行为 命中状态
table inet atomdns (本套件) dstnat - 10 iifname br-lan 53 重定向到指定端口 率先命中 ⭐
sing-box prerouting_prematch dstnat - 1 前置匹配 已接管跳过
HomeProxy / sing-box prerouting dstnat + 2 LAN :53 强行 DNAT 进 TUN 代理 已被提前接管
dnsmasq prerouting dstnat + 5 常规路由器监听 压在最后

接管流量流向与模式切换

在 LuCI 高级设置中可一键切换，立即生效并持久化

Relay 模式特点： LAN 客户端发送到 53 的 DNS 请求经由 dnsmasq 转发到 AtomDNS 5335。
优势：完美保留路由器本地 DHCP 名字（如 my-nas.lan）解析。
审计日志：客户端身份统一显示为 127.0.0.1。
Step 1 LAN 客户端 请求 :53
Step 2 dnsmasq :53 解析 .lan 本地主机
Step 3 AtomDNS :5335 SRS 规则库智能分流
Step 4 上游解析 国内直连 / 国外代理
Direct 直连模式特点： LAN 客户端对 53 的请求直接由 nat 链重定向到 AtomDNS 5335，完全绕过 dnsmasq。
优势：AtomDNS 控制台与审计日志中可精准记录每台终端真实的内网 IP (如 192.168.1.108)。
注意：将无法通过 dnsmasq 自动解析 DHCP .lan 域名（可按需写入 hosts）。
Step 1 LAN 终端设备 192.168.1.X:53
Step 2 (直接命中) AtomDNS :5335 记录真实客户端 IP 审计
Step 3 分流器出口 国内腾讯/阿里 DoH · 国外 sing-box

Comprehensive Features

为生产级软路由打磨的 12 项匠心特性

从底层内核 nat 劫持、服务守护，到上层现代 Web 控制台，全链路闭环保障稳定运行。

🧩 单包完整安装

一个 .apk 包含了核心程序、优化配置、procd 守护、LuCI 管理页面与全部接管控制脚本，无需四处找依赖。

🔀 DNS 自动接管

启动服务即可把 LAN 的 :53 端口流量交给 dnsmasq 处理，再转发到 AtomDNS :5335，并无缝注入抢占规则。

↩️ 毫秒级可逆恢复

自动留存系统 dnsmasq 的快照状态。停止服务时自动清理 nft 规则并还原快照，全屋网络瞬间平滑回退，零断网风险。

🛡 失败安全保护

原子化状态检查：若 AtomDNS 进程异常未能监听端口，接管脚本绝不会修改 dnsmasq，避免把全网 DNS 指向死端口。

🖥 LuCI 原生控制台

基于现代 JavaScript 原生编写（无冗余 Lua CBI 依赖），提供内存、PID、运行时间、接管开关、端口与模式配置。

📜 中文结构化日志

日志直观展示中文标注，支持按来源（服务、接管、守卫）与级别（INFO、WARN、ERROR）过滤，不必费劲跳转系统日志。

🚀 代理透明共存

默认 RealIP，国外 DoH 通过 HomeProxy/sing-box 的 TUN 自动走代理，防止 DNS 污染；也可指定 SOCKS5 上游。

🔁 开机回滚守卫

即使关闭了自启后重启路由器，专属 recover 启动脚本仍会在引导阶段自动还原 dnsmasq 默认配置，绝不留暗坑。

🛡 30秒接管保活自愈

procd 常驻 watchdog 实例每 30 秒自检。当 HomeProxy、fw4 重启或手动改动冲刷了 nft 链，自动修回接管规则。

🧑‍💻 真实客户端模式

在 LuCI 高级设置中可随心切换 relay 与 direct 模式，满足局域网名字解析与终端精准审计两种诉求。

🧬 CI 智能规则注入

构建阶段自动同步最新 SRS 分流规则，内置腾讯与阿里 DoH / DoT 优化配置，并注入中国大陆直连白名单。

🧪 规范的自动化流水线

GitHub Actions 驱动：rustup 1.96 交叉编译静态二进制 → 校验 sha256 组装源包 → 官方 SDK 打包 apk → 发布 Release。

Getting Started

3 步完成安装与接管

无需繁琐的编译与复杂的 iptables / nft 规则调试，标准 apk 单包开箱即用。

1

下载并传输 APK 安装包到路由器

从 Release 页面下载最新的 atomdns-1.0.0-r1.apk，通过 scp 上传至软路由 /tmp/：

scp atomdns-1.0.0-r1.apk root@192.168.1.1:/tmp/
2

执行 APK 安装（自动初始化并启动）

SSH 登录路由器，使用 apk-tools 执行安装（自建包带 --allow-untrusted）：

ssh root@192.168.1.1
apk add --allow-untrusted /tmp/atomdns-1.0.0-r1.apk
✨ 安装后服务端口： DNS 监听 127.0.0.1:5335 · 独立 WebUI http://<router>:9099/ · LuCI 菜单在 「服务 → AtomDNS」
3

确认 dnsmasq 转发（可选确认）

服务启动时会自动做好接管与状态快照备份；若需手动确认，可执行如下 uci 指令：

uci set dhcp.@dnsmasq[0].noresolv='1'
uci -q delete dhcp.@dnsmasq[0].server
uci add_list dhcp.@dnsmasq[0].server='127.0.0.1#5335'
uci commit dhcp
/etc/init.d/dnsmasq restart
与 HomeProxy / sing-box 协同共存注意事项
  • 避免回环：代理客户端（HomeProxy/sing-box）自身的内部 bootstrap DNS 切勿指向 AtomDNS 5335，请保持它自用的 bootstrap/DoH 上游。
  • SOCKS 地址规范：AtomDNS 国外组填写的 SOCKS5 代理只接受 IP:端口（如 127.0.0.1:5330），不接受域名。
  • 自愈防护：当保存并应用 HomeProxy 导致防火墙规则被重刷时，AtomDNS 的 30 秒后台巡检守卫会自动修回，您无需手动干预。
